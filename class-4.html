Autonomy

Agent autonomy

From hands-on to hands-off — and every step in between

01
Manual

You ask, the agent does

You stay in the chat. Every step is a request — the agent just executes what you tell it to do, one shot at a time.

02
Connected

You ask — across tools

Same flow, but now the agent can reach into other apps (Figma, Slack, Notion, GitHub…) and act there on your behalf.

03
Scheduled

You set a routine

You define when the agent should run — every Monday, after each PR, at 9am — and it works alone on that cadence.

04
Autonomous

It decides on its own

The agent watches for conditions and acts when they're met — no schedule, no chat, no nudge.

Build

How to build an agent

Four things you tell Claude when you spec it out

1
Knowledge

What it should know

Define the agent's domain expertise and the experience it draws on — what counts as the "right" answer here.

2
Action

What it should do

Spell out the process step by step — the method, the tools (skills), and the order of operations.

3
Cadence

When and at what pace

Set the rhythm — once a week, on a trigger, or always-on — and how aggressively to push toward completion.

4
Decisions

How to react to each case

Define the edge cases up front: if X, then Y — not X, but Y.
